# 100 AI Prompts That Actually Work
## Copy-Paste Prompts for ChatGPT, Claude & Gemini

### 💰 MAKE MONEY (20 Prompts)

**1. Business Idea Generator**
```
I have $[X] and [Y] hours per week. Give me 5 business ideas I could start this week that could make $1000/month within 90 days. For each idea, include: startup cost, time to first dollar, and step 1 to start today.
```

**2. Side Hustle Finder**
```
Based on these skills: [list your skills], suggest 10 side hustles I could start this weekend with zero upfront cost. Rank by income potential and time to first payment.
```

**3. Freelance Proposal Writer**
```
Write a winning freelance proposal for this job: [paste job description]. Make it personal, address their specific needs, and include a hook that makes me stand out. Keep it under 150 words.
```

**4. Product Description That Sells**
```
Write 3 product descriptions for [product] targeting [audience]. Use the PAS framework (Problem, Agitate, Solution). Make the first one short (50 words), second medium (100 words), third long (200 words).
```

**5. Cold Email That Gets Replies**
```
Write a cold email to [type of person/company] offering [service]. Use this framework: compliment, problem, solution, soft CTA. Keep it under 100 words. Sound human, not salesy.
```

**6. Pricing Strategy**
```
Help me price my [product/service]. My costs are [X], competitors charge [Y-Z], and my target customer is [description]. Give me 3 pricing options with pros/cons and which you recommend.
```

**7. Sales Page Outline**
```
Create a sales page outline for [product] priced at $[X]. Include: headline options, pain points, benefits, social proof sections, FAQ, and 3 different CTA variations.
```

**8. Upsell/Cross-sell Ideas**
```
I sell [product]. Give me 10 upsell and cross-sell ideas that would increase average order value by 30%+. For each, estimate the price point and conversion likelihood.
```

**9. Passive Income Brainstorm**
```
I'm skilled at [X] and have [Y hours/week]. Give me 5 passive income ideas I could build over the next 3 months. Rank by: time to build, maintenance required, income ceiling.
```

**10. Negotiate Salary/Rate**
```
I'm [role] with [X years experience]. Current salary is $[Y]. Help me prepare to ask for $[Z]. Give me: 3 key points to make, how to handle objections, and exact phrases to use.
```

**11. Client Retention Email**
```
Write an email to a client I haven't heard from in 3 months. Goal: restart the relationship without being pushy. Include a reason to reconnect and soft pitch for new work.
```

**12. Testimonial Request**
```
Write a message asking my customer for a testimonial. Make it easy for them by including 3 specific questions they can answer. Keep it friendly and not awkward.
```

**13. Launch Sequence**
```
Create a 5-email launch sequence for my [product] launching in [timeframe]. Include: teaser, value email, social proof, objection handler, and final call with urgency.
```

**14. Refund Response**
```
A customer wants a refund for [product] because [reason]. Write a response that: acknowledges their concern, offers a solution, and if refund is necessary, ends on a positive note.
```

**15. Partnership Pitch**
```
I want to partner with [company/person] for [goal]. Write a pitch that shows what's in it for them, proves I'm credible, and makes saying yes easy.
```

**16. Content Monetization**
```
I have [X followers] on [platform] in the [niche] space. Give me 10 ways to monetize this audience, ranked by revenue potential and effort required.
```

**17. Course Outline Creator**
```
Create a course outline for teaching [topic] to [audience]. Include 6-8 modules, 3-5 lessons per module, and one practical exercise per lesson. Target completion time: [X hours].
```

**18. Coaching Package Designer**
```
I want to offer coaching in [area]. Design 3 packages (basic, standard, premium) with different deliverables, time commitments, and price points. Include what makes each level worth the price jump.
```

**19. Affiliate Marketing Plan**
```
I want to do affiliate marketing in [niche]. Give me: 5 high-commission products to promote, content ideas for each, and the platform strategy that works best for each.
```

**20. Gig Economy Optimizer**
```
I do [gig work] and make $[X]/hour. Give me 5 specific tactics to increase my hourly rate by 50% without working more hours.
```

### 🎯 PROBLEM-SOLVING & CREATIVITY (20 Prompts)

**81. Reverse Engineer Success**
```
[Person/Company] achieved [success]. Reverse engineer how they did it. What specific actions, decisions, and timing contributed? What can I replicate for my situation: [context]?
```

**82. First Principles Thinking**
```
Apply first principles thinking to this problem: [problem]. Break down all assumptions, question each one, and rebuild a solution from fundamental truths.
```

**83. Pre-Mortem Analysis**
```
I'm about to [project/decision]. Conduct a pre-mortem: imagine it failed completely. What went wrong? List all possible failure modes and prevention strategies for each.
```

**84. Second-Order Effects**
```
If I [action], what are the second and third-order effects? Map out the ripple effects, both positive and negative, across different areas of my life/business.
```

**85. Contrarian View**
```
Everyone says [common belief about topic]. Give me the strongest argument for the opposite. What evidence supports the contrarian view? When might the minority be right?
```

**86. Pattern Recognition**
```
I've noticed [observations]. What patterns do you see? What might be causing this? What predictions would these patterns suggest? How can I test my hypotheses?
```

**87. Creative Constraint**
```
I need to [goal] but I have these constraints: [list limitations]. Use the constraints as creative fuel. Give me 10 innovative solutions that only work BECAUSE of the constraints.
```

**88. Stakeholder Mapping**
```
For this decision/project: [describe]. Map all stakeholders. For each: their interests, their power, potential objections, and how to get them on board.
```

**89. Scenario Planning**
```
Plan for 3 scenarios for my [business/project]: Best case, worst case, most likely. For each scenario: triggers that indicate it's happening, response strategy, and preparation needed now.
```

**90. Innovation Prompts**
```
Generate 20 "what if" questions for [industry/product/service] that could lead to innovation. Make them increasingly wild. Then pick the 3 most promising to explore further.
```

**91. Problem Reframe**
```
I've been trying to solve [problem] by [approach]. Reframe the problem 5 different ways. Maybe I'm solving the wrong problem entirely. What question should I really be asking?
```

**92. Analogous Solutions**
```
[Problem] in my field. Find 5 analogous problems in completely different fields. How were they solved? Can I adapt those solutions to my context?
```

**93. 10x vs 10%**
```
I want to improve [metric] by 10%. Now force me to think about improving it by 10x. What would have to be true? What completely different approach would that require?
```

**94. Resource Inventory**
```
Help me inventory my underutilized resources: skills, connections, assets, knowledge, time slots. For each, suggest unexpected ways I could leverage it for [goal].
```

**95. Synthesis Engine**
```
Combine these seemingly unrelated concepts: [A] and [B]. What new ideas emerge at the intersection? Push for novel combinations that haven't been tried.
```

**96. Devil's Advocate**
```
I've decided to [decision]. Be a rigorous devil's advocate. Find every flaw in my reasoning, challenge my assumptions, and present the strongest case against this decision.
```

**97. Future Back Planning**
```
It's [5 years from now] and I've achieved [goal]. Work backwards: What had to happen in year 4? Year 3? Year 2? Year 1? Next quarter? This week?
```

**98. Simplicity Filter**
```
My [project/system/process] has become complicated. Apply a simplicity filter. What can be eliminated entirely? What can be combined? What's the minimal viable version?
```

**99. Energy Audit**
```
List all my current projects/commitments: [list]. For each: energy it gives vs. takes, alignment with my goals, and recommendation (double down, maintain, reduce, eliminate).
```


**The Prompt Improver**
```
Improve this prompt for better AI results: [paste prompt]. Make it more specific, add useful constraints, include output format, and add examples if helpful.
```

**The Role Setter**
```

```

**The Iterative Refiner**
```

```

## How to Get the Best Results

1. **Be specific** - Vague prompts get vague answers
2. **Give context** - The AI isn't psychic, tell it about your situation
3. **Specify format** - Want bullets? Tables? Step-by-step? Say so
4. **Iterate** - First response not perfect? Ask for improvements
5. **Use examples** - "Write something like this: [example]"
