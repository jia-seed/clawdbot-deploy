# EMAIL_RULES.md

## Discord Reporting Rules

**ONLY post to Discord when you have TAKEN ACTION on an email.** Actions include:
- Sent a reply
- Scheduled/booked a meeting
- Flagged something urgent for jia
- Created a calendar event

**DO NOT post to Discord for:**
- Skipped/ignored emails (newsletters, promos, automated notifications, spam)
- Summary tables of emails you did nothing about
- "X emails checked, 0 replies sent" reports
- HEARTBEAT_OK (just reply HEARTBEAT_OK silently to the heartbeat, dont post it to discord)

**Format when reporting an action:**
```
[email] from: Name | subject: Subject
brief context
action: what you did (replied, booked, flagged)
```

If you checked emails and took zero actions, do NOT send any message to Discord. Just move on.
